# No Ice No Gain

Landing page do No Ice No Gain, sorvete proteico feito para quem treina.

## Conteúdo

- `index.html`: landing page completa, em HTML/CSS/JS puro (sem dependências externas além das fontes do Google Fonts). Funciona direto no navegador ou publicada via GitHub Pages.
- `assets/logo.svg`: logotipo (ícone) em SVG, pronto para uso em favicon, redes sociais etc.

## Paleta

- Azul (marca): `#0B84B8`
- Azul claro (destaque/fundo): `#8FDCF5` / `#EAF8FD`
- Tinta (texto de título): `#0E3A52`
- Texto de corpo: `#3C6478`
- Branco: `#FFFFFF`

## Publicar no GitHub Pages

1. Em **Settings > Pages** do repositório, escolha a branch `main` e a pasta raiz (`/`).
2. Salve. O site fica disponível em `https://<usuario>.github.io/noicenogain/`.
